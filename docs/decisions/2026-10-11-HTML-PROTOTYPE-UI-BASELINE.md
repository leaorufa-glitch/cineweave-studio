## 已明确的产品要求

1. **后续真正开发时，用户新提交的完整 HTML/CSS/JS 七页面原型是界面布局、交互、视觉和信息架构的首要依据**；不能把旧 V1.4 文字交互草案或仓库中的其他旧原型作为更高优先级。
2. **旧 V1.4 设计文字可以退为历史参考或归档**，不再对新 HTML 的已表达布局、交互、导航提出相反的默认实现要求；应在 HTML 入库、核对相关引用后考虑迁移/删除，避免文档死链。
3. 已确认的业务语义与技术验收仍然有效：六个专业工作区、同一 Director Shot、第 4 区规划 Clip、Shot↔Clip 多对多、人物正式一张 2:3/2×2 宫格、场景和关键道具一张 1+3 图板、声音身份和基准语速、自有 H3 长期优先、真实 Run/Take、连续性和可导出成片。
4. **若原型演示图片/演示数据与正式资产不变量不同，保留原型的界面交互与视觉语言，但在真实业务接入时正确显示正式资产标准；不把示例占位图当作生成质量/媒体已就绪的证据。**
5. 原型是 UI 演示，不代表 H3、GPT Image 2、AI、持久化、正式上传、付费任务和 Render 已实现。所有实功能必须按业务合同开发、验证。
6. 后续 Codex 的第一任务应是**基于新原型而非新设计一套 UI**，将七页面外观、导航、交互纳入未来工程；现有代码/旧原型可供参考，但不得未经明确讨论替代新上传文件。
