# V1.3-10｜第 2 区声音资产规范 V1：角色人声、语速、环境与关键声

> **状态：详细设计草案，待创作者审定**；2026-10-10  
> **已确认方向**：[PD-008：角色声音与语速](../decisions/2026-10-10-VOICE-ASSET-DIRECTION.md)。本文件提出的具体字段、计量方式、样本配额、UI 控件、验收规则仍待设计审定。  
> 已有电影生产约束：H3 主力、V1 单次 Clip ≤15 秒，优先在模型真正支持时使用原生音画；LLM 贯穿六区、系统保留正式事实和不可变 Run/Take。

> 不生成音频/视频、关系图、图像或网站程序，不调用模型 API，也不假定已验证任何 H3 路由的语速控制或声音克隆功能。

## 一、声音资产的职责边界与真正用途

角色声音不仅是“发出一句话”，还体现人物身份、年龄感、气质、情绪表达习惯、口音、**语速**和听觉连续性；环境声建立空间；特定道具/动作声音承载剧情线索。

第 2 区负责**稳定的、可复用的听觉身份与素材**，不是负责每句对白的表演导演：

| 工作区 | 应做的事 | 不做的事 |
|---|---|---|
| **1 前期创作** | 确认台词原文、人物说话特点、潜台词、语言及因果 | 不为每句台词硬编码具体语速 API |
| **2 资产设计** | 确立声音身份、**基准语速**、基础音色/口音、声音参考与正式版本；按需建立环境/道具声参考 | 不替导演决定该句如何演绎 |
| **3 导演创作** | 按场景戏剧目的决定声音表演，包括**当前表演语速**、力度、节奏、气声、停顿的艺术意义 | 不因为某句加快就改成另一个角色的 Voice Identity |
| **4 分镜与生成规划** | 在同一 Shot 的视听计划中绑定角色声音身份、对白、台词级语速变化、停顿、声音事件和时长 | 不假装语速数值一定是视频模型可直接传入的参数 |
| **5 生成制作** | 按真实模型/模式能力编译语音目标或引用合法声音媒体，记录所用正式版本与实际调用 | 不以 Prompt 写有语速就宣称模型准确执行 |
| **6 审片与成片** | 播放实际音视频，评估音色、语速、停顿、口型、表演情绪及跨 Clip 连续性，定位返工来源 | 不将“模型完成”当作声音质量合格 |

原则：声音和图像同样是影视创作资料，但**声音资产层与镜头表演层要分开**。第 2 区专注能跨 Scene/Film 稳定复用的声音身份，第 3/4 区控制具体表演。

## 二、角色声音资产的 V1 建议结构

### 2.1 Voice Identity（声音身份）

一个角色默认有一个可追溯的基础 Voice Identity；如果剧情设定确实存在跨年龄/长期伪装或显著的声音变化，可以保留关联的合法声音版本/状态，但不能随一个镜头的情绪自动生成新身份。

**建议的声音身份卡**：

| 字段（业务概念） | 说明 | 示例（仅演示，不是真实角色样音） |
|---|---|---|
| Character 与 Voice Identity | 当前声音属于哪个人物，和哪些电影/集关联 | 女儿 / VOICE_DAUGHTER |
| 语言与方言/口音 | 语言、地域特色、自然度；避免过度表演化标签 | 普通话，自然口语 |
| 音色与音高倾向 | 稳定的声线质感与音域；不等于当场声音大小 | 清亮偏冷、略低音区 |
| **基准语速（必有独立项）** | 人物**平时说话**的快慢倾向；不能藏在情绪备注 | 中等偏慢 |
| 基础发音与节奏 | 咬字、连读、短句习惯、呼吸与语句组织倾向 | 平时句尾不刻意拖长，重要内容略停顿 |
| 基础参考媒体 | 真实样音文件及已采纳版本、可播放状态 | VoiceReference Rev 2（音频实际存在） |
| 来源与版本 | 由导入/许可使用/生成得到，当前采纳记录 | 用户导入、专业 AI 建议后采纳 |
| 适用性标志 | 是否能被某个实际模型/模式作为声音参考输入 | H3 当前路由：待验证／支持／不支持 |

不要把“音色”、“音高”、“音量”、“情绪”、“语速”、“停顿”和“台词时长”写成一个不可拆的自由文本属性；它们互相关联但不可互相替代。

### 2.2 语速：两个层次、一个优先级规则（已确认方向）

**角色基准语速**是第 2 区的长期角色特征，比如“中等偏慢，遇到敏感话题更谨慎”；**场景/台词表演语速**是第 3 区导演按情节临时决定的表达，由第 4 区落实到对白/视听时序。

推荐优先级（待细化）：**对白/时段的导演语速要求 > 本场的表演语速设置 > Voice Identity 基准语速**。没有覆盖时继承基准语速，使用过后不会修改 Voice Identity。

| 情况 | 应采用 | 错误做法 |
|---|---|---|
| 女儿日常说话 | 基准：中等偏慢 | 每个 Clip 随机变成健谈快语速 |
| 女儿与父亲争执 | 当前台词：较基准明显加快 | 重新创建一个“吵架女儿声音身份” |
| 女儿情绪低落 | 当前台词：较慢、气息弱、适当空白 | 机械把音频整体放慢导致声音失真 |
| 同一句里前慢后快 | 用一句/片段内的语速段落目标 + 明确停顿 | 把整句都设为固定高倍速 |
| 父女交谈，随后沉默 2 秒 | 语速独立，另记**2 秒停顿** | 用“语速特别慢”代替静默 |
| 角色在不同 Clip 连续说话 | 基于相同 Voice Identity、当前表演策略做一致性检查 | 只因换 Clip 就完全换了说话习惯 |

### 2.3 语速怎样记录：人可理解优先，量化辅助

**推荐 V1 默认**先采用“很慢 / 偏慢 / 自然中等 / 偏快 / 很快”或自然语言语速倾向，并可在真实样音上试听；不预设所有中文角色必须同一个数值标准。

可选的可测量描述（未来实测确认后启用）：

- **中文**：可记录一段样音的有效汉字/秒（不把标点作为汉字），另记录**整句含停顿平均字/秒**。两者不同：角色说话速度与故意停顿不能混为一谈。
- **英文或其他语言**：可按语言适合的词/分钟、音节/秒等方式测量；不得将中文每秒字数公式直接照搬。
- **相对语速**：若有真实样音的基准速度，可记录“比角色基准略快/明显慢”等相对目标；**不推断模型一定支持 `speed=1.1` 之类 API 字段**。
- **表演停顿**：作为独立的秒数或时间区间，在第 3/4 区确定；镜头/Clip 计划需要时才填写。
- **时长预算**：对白计划、动作与自然停顿一起约束 15 秒 Clip；文字字数估算只作为**预测**，真正可否说完要通过朗读或生成后音频检查。

要避免一种常见错误：“语速 1.5 倍”被直接当作音频后期拉伸倍数。人物说得更快是**表演意图**；改变已录制的波形时长会影响音质、节奏与可能的口型同步，不能作为默认实现方式。

### 2.4 Voice Mode（表演模式）

同一 Voice Identity 可有可选模式，例如平静、压抑、争执、疲惫、低声、回忆旁白。建议模式表达以下差异，而**不产生新的声音身份**：

- 当前语速相对基准的变化、局部快慢；
- 音量、气息、音高起伏、力度、咬字和情绪控制；
- 特殊停顿、句尾处理、实际对白节奏；
- 可选的真实表演参考样音（若实际模型接收）。

Voice Mode 是便于导演复用的表演参考，而不是每句台词必须归类到几个固定音色包。可在第 3/4 区直接覆盖单次表演要求。

### 2.5 Voice Reference Media（基础声音样本）

建议主要角色至少有**一条已采纳的清晰、可播放、语气中性的基础声音样本**；重要表演模式可按需存 1～2 条情绪样音。配角建议具有声音身份说明，可根据出场/对白重要性创建正式参考，避免为无声临时人物无意义生成音频。

- 样本尽量少环境噪声，便于辨认音色、咬字及基准语速；避免 BGM 混杂。
- 样本记录所读语言、实际时长、是否含刻意停顿、实际语速观察、媒体出处及正式版本。
- 不将标准测试台词写死为所有角色必须同一句话；可以用统一比较方式检查相对语速和音色。
- “实际保存一段参考音频”与“当前 H3 模式能读取此音频作声音锚点”是两件事。后者必须实测验证。
- 若某个目标 H3 模式不接受声音样本，只能把 Voice Identity 的合理语言描述编入受支持的请求位置，并将**跨 Clip 声音一致性视为审片风险**；不伪装为已经锁定声音。

**样本时长、文件格式/声道/采样率、可用参考数量与具体质量阈值**属于 V1.5 根据目标音频/视频 API 和真实素材验证后确定的技术合同，不在此草案随意捏造。

### 2.6 V1 角色样音最低交付合同（**推荐草案，待创作者确认**）

这一节把“有声音身份”“确实有可播放样音”“样音能被当前 H3 模式直接引用”三个不同状态严格分开。**不能为了制作人员声素材而强迫整套电影流程等待；也不能用文字声音设定冒充真实音频锚点。**

#### 分角色交付等级

| 人物范围 | 必要创作信息 | 建议的实际媒体最低目标 | 不应强制 |
|---|---|---|---|
| **有台词的主要人物／反复出现的对白角色** | Character 绑定的 Voice Identity、语言/口音、稳定音色描述、独立**基准语速**、基本发音特点 | **一条当前正式采用的中性、干净、可试听基础样音**；真实文件、来源和版本可核查 | 不强制每种情绪都制作样音；不自动要求配套外部 TTS |
| **有少量台词的配角或临时声音角色** | Voice Identity、语言/口音、音色、独立基准语速 | 根据戏份、跨镜头复现需求和目标模型能力决定是否制作一条基础样音 | 不因一句台词强制上传多段音频 |
| **没有台词、也没有独立人声表演的角色** | 角色身份；需要时记录无台词/无声音资产状态 | **不要求样音** | 不得为资产完整度自动收费生成语音 |
| **重要旁白/画外音** | 指定说话身份、叙述语气和独立基准语速；可关联角色或独立旁白身份 | 如果跨影片反复出现，按主要对白角色的标准建议配一条清晰基准样音 | 不把所有环境广播或背景人群声认成独立人物 |

这里的“主要人物一条样音”是**V1 推荐资产质量目标**，不是已经证明 H3 必须提供某个音频字段。是否作为正式素材验收的强制项、缺样音是否可以直接生成视频，应由创作者确认。凡涉及实际付费样音生成，仍遵守有效授权与预算。

#### 一条合格基础样音应该是什么样

1. **说话内容**：以该人物自然语言讲述一段完整、可辨认的内容；含正常句子转折和自然连读，避免只念一个词或只发声。优先采用专门写的中性测试文本或授权台词，不要让剧透、过激情绪干扰身份锚定。
2. **语速**：在第 2 区记录的**基准语速**下自然说话；不得为了凑样本时长强行加快或拉伸录音。记录“基准语速档位”和听感；实际可测语速可以后续补充。
3. **清晰度**：音色辨认清楚、咬字自然、响度基本稳定；尽量避免明显的音乐、环境音、混响和失真、削波、刺耳噪声。
4. **情绪**：以中性、自然口语为主，不要用哭泣、嘶吼或戏剧化喘息作为唯一身份样音；这些可归到后续可选表演样本。
5. **来源**：支持用户导入已授权的音频或经过授权的声音生成；保存来源、许可/使用权状态、原始文件、版本、语言、实际时长和是否采用；未授权的真实人物声音不得直接作为可复制声音模板。
6. **样本时长**：**建议用于人工试听的工作区间约 10–20 秒**，只为审阅音色和语速方便，**不是任何 TTS、声音克隆或 H3 API 的已验证限制**。如果实测某路由对长度有要求，以合规模型规格为准；素材时长与视频 Clip 单次 ≤15 秒约束**互不等同**。
7. **文件合格**：实际文件能播放、能下载/被服务器合法访问、媒资编码信息可检测。具体格式、声道、采样率、比特率不在未核实模型文档时预设固定值。

**可选的表演样音**：主要角色可以按戏剧需要再补一条“愤怒/哽咽/压低声”等样音，但**不是必做**，且必须标注仍属同一个 Voice Identity 的表演参考。第 3/4 区可以不依赖样音而描述单句表演。

#### 两种独立的“就绪”状态

| 状态 | 判定 | 可以/不可以声称 |
|---|---|---|
| **Voice Defined** | 有角色的正式声音描述、基准语速和版本 | 可做故事、导演与分镜；**不能声称已有样音** |
| **Sample Ready** | 有当前正式样音，文件可访问、可试听、内容/音质已审阅 | 可声明声音资产有样音；**不能据此声称视频模型一定接受** |
| **Model Reference Compatible** | 对某一个具体模型路由/模式实际验证了样音输入的合法性与效果 | 仅对已验证的**具体路由和模式**标注可用，不推广到全部 H3 |
| **Take Audio Reviewed** | 真正播放并审查该 Run/Take 的音频 | 可对**该次实际媒体**判断音色与语速，不暗示后续 Clip 必然一致 |

上述状态可并存，是**不同类型的证据**，不强制设计成四级不可逆进度条。

#### H3 原生音画工作模式的处理

- 若实际 H3 模式支持合规的声音参考输入，按要求检查并引用**真实媒体和当时采用的版本**。
- 若目标 H3 模式只支持通过提示词表达说话方式，而不支持输入声音样本，则第 5 区可以在用户授权范围内继续创作，但须标注：**声音身份仅通过描述约束，跨 Clip 声线一致性风险未解决**。不要传入虚构的 `voice_ref`、`speed` 等字段。
- 若用户对该片有**强制保持指定人声**的特殊要求，而当前路由无法满足，应提示改选已验证的技术策略或专业人工介入，**不能把风险提示当成已经满足强制条件**。
- 第 6 区通过实际影片和对白时码评价是否“像同一个人”、说话是不是符合基准/导演表演速度，严重不一致则定位返工，必要时评估真实模型能力或追加可行声音方案。
- 不强行把原生音画生成转为全片外部配音后期；只有在制作目标和模型限制需要时才选择另一路线，尊重低摩擦制作目标。

#### 这一节的最低验收补充（待批准）

| ID | 用例 | 预期 |
|---|---|---|
| VO-11 | 主要对白人物仅有 Voice Identity，无样音 | UI 准确显示 **Voice Defined / Sample Missing**；仍可做编剧、导演、分镜；是否禁止视频生成由已批准的制作约束和目标模式决定 |
| VO-12 | 上传样音含背景配乐或强哭喊 | 提示可能不适合作为中性身份样音，可作为其他参考候选；不能自动通过中性质量审核 |
| VO-13 | 导入基础样音，但未验证 H3 音频参考接口 | 可以标记 Sample Ready，**不能**标记 Model Reference Compatible |
| VO-14 | 某台词使用较基准快的导演表演语速 | 不重录基础样音、不改变 Voice Identity；第 4 区记录单句语速与停顿 |
| VO-15 | 用户尝试以不具使用权的真实人声做复现 | 提示先确认使用许可，不自动生成或使用该样音 |
| VO-16 | 当前 H3 路由不能读取样音 | 不创造不存在的模型参数；给出合法的声音描述编译或明确不满足指定声音的一致性要求 |
| VO-17 | 同角色下个 Clip 出现明显不同的声线 | 对实际音频进行跨 Clip 审听并标注证据，不因为已有样音就自动判定一致 |

**待创作者选择的最小产品规则**：有台词的主要角色是否按“一条中性基础样音”为正式质量目标；若 H3 具体模式暂不支持声音参考，是否允许在明确风险提示下继续生成？两者都不应被解释为现有 H3 接口已验证。

## 三、环境声音和剧情关键声音：轻量但真实

### 3.1 环境声（Sound Environment）

同一场景环境可以定义正式**声音设定**：雨声强度、空间混响、室内电器底噪、远处列车、广播的空间位置和事件密度。

推荐设计：

- 绑定 Location / Environment State 与影片段落，说明空间声学与主导声音。
- 可以先是专业文字设定；重要场景按需保存真实音频参考。
- 不为同一场景每个 Shot 复制一份独立“环境声音身份”。
- 第 3 区决定导演意义：这场戏究竟要听见列车，还是刻意保留沉默。
- 第 4 区安排具体声响的出现、消失、遮蔽与动作/对白关系。
- 第 5 区优先利用已验证的原生音画能力，若模型不支持该声音实现方式再评估补充生成或必要轻后期。

### 3.2 关键动作和道具声（Sound Cue / Foley Reference）

例如钥匙掉地、门锁开启、列车汽笛、手机振动。只把**剧情重要或跨镜头需要一致**的声音独立作为资产。

建议一个关键声音设定至少能表示：

- 对应哪个 Prop 或故事事件、声音要表达什么；
- 材质、距离与空间类型（钥匙落在石地/木桌上的声音不同）；
- 是否有真实参考媒体，来源和采用版本；
- 具体发生的时间由 Shot/Clip 的 Sound Cue 决定，不仅是资产库“有一段声音”；
- 第 6 区按真实音频检查是否出现、是否过强/过弱、是否符合叙事与空间。

不建议把所有普通脚步声/衣服摩擦声音都做成强制独立资产包。重要音乐主题与具体影片配乐决策仍属全片导演/成片工作，不因为“声音资产”而全部转移到第 2 区。

## 四、第 2 区声音资产的真实交互与版本管理

**推荐的工作区操作（草案）**：

1. 从 Character 打开“声音”页签，编辑 Voice Identity；看到独立字段**基准语速**和可试听基础样本。
2. 对需要的角色提出声音方案，专业 LLM 解释音色、口音、基准语速与人物性格/剧本的对应关系；产生**候选**。
3. 用户上传/生成声音参考，试听并选择正式 Voice Reference；保留历史候选，不会静默覆盖已生成 Run 的音频来源。
4. 进入导演工作区，用户选中 Scene/Shot 时默认继承角色声音和基准语速，设置该场/某句需要变快或变慢。
5. 分镜工作区把逐句台词、说话角色、表演语速、重要停顿和声音事件放进视听时间计划；允许 AI 提示对白过密、留白不足。
6. 生成制作工作区显示“角色基础声音/基准语速/当前表演覆盖/语音参考是否被模型支持”，并以实际模型路由合法输入提交。
7. 审片工作区对照真正播放出来的对白，用时间码标记“声音身份漂移”“语速过快”“停顿不够”“音色错误”“口型与对白不同步”等问题，并可定位返回第 2/3/4/5 区。

### 4.1 概念对象

| 业务对象 | 含义 |
|---|---|
| **Voice Identity** | 绑定角色的长期声音设定，包含独立**基准语速** |
| **Voice Revision** | 声音身份/基准语速的版本化正式改动，历史保留 |
| **Voice Reference Media** | 真正可播放的基础或可选表演样音 |
| **Voice Mode** | 同一声音身份下可复用的表达模式，包含可选相对语速/气息/力度 |
| **Dialogue Performance Instruction** | 第 3/4 区对具体台词或时间段的表演语速、停顿和力度覆盖 |
| **Sound Environment** | 场景可复用的环境声音设定 |
| **Sound Cue Asset** | 关键道具/动作声音参考及采用版本 |
| **Compiled Sound Target** | 经过具体模型合法性检查的声音输入/描述快照，不能伪造目标接口不支持的参数 |
| **Observed Audio QA** | 实际 Take 的语速、音色、台词、口型/时序与声音连续性观察 |

业务对象不是已经批准的数据库表名。

### 4.2 改变语速时，哪些对象需要改版？

- 改变人物长期**基准语速**：属于 Voice Identity 正式 Revision；关联下游需要复核，但过去已生成 Take/Run 的实际音频与输入快照保留。
- 某句对白演得更快：只修改对应的 **Dialogue Performance Instruction** 或 Shot/Clip 版本，不修改人物的基准声线。
- 用户把一个“基准偏快”的声音样本重录得更干净：同 Voice Identity 的 Voice Reference 候选/新版，不因为文件更换创建另一个人物身份。
- 剧本原文改变：第 1 区正式 Screenplay Revision 可能影响对白时长、节奏与 Clip 计划；声音资产本身不因此自动失效。

## 五、V1 业务质量验收与模型适配

| ID | 验收场景 | 应当成立的结果 |
|---|---|---|
| VO-01 | 在第 2 区打开有台词的主要角色 | 能看到明确 Voice Identity、**独立基准语速**和当前正式声音描述/参考状态 |
| VO-02 | 保存角色的“中等偏慢”基准语速 | 进入多个 Scene/Shot 可复用，不依赖聊天记忆重新猜 |
| VO-03 | 导演设定某句台词“语速加快并留出 1 秒停顿” | 第 3/4 区存入本句表演指令；**不更改 Voice Identity** |
| VO-04 | 规划一个 V1 15 秒 Clip 包含多句对白 | 系统提醒朗读时间、呼吸/停顿和动作的预算风险；不只用字数生硬决定真实结果 |
| VO-05 | 某视频模式不支持声音参考或精确语速参数 | 第 5 区明确限制，使用合法可表达的替代语言指令或返回调整计划，不发送虚构字段 |
| VO-06 | 有正式声音样本但音频链接/文件缺失 | 真实媒体检查不能通过；不会把描述文本冒充已经可播放的样音 |
| VO-07 | 生成 Take 声音与角色基准差异明显 | 第 6 区标注真实观察与音频时间码，可返回资产/导演/编译/生成环节查因 |
| VO-08 | 同角色跨多 Clip 表演语速不同 | 若符合不同场次导演意图，可以通过；不机械把所有 Clip 拉到相同速度 |
| VO-09 | 角色语速被改为新版基准 | 相关未来任务或计划待复核；已生成历史 Run/Take 的语音不会被修改 |
| VO-10 | 环境声/道具声作为必要效果 | 第 2 区有可追溯设定/参考，第 3/4 区决定叙事意义与时序，第 5/6 区据真实能力和真实媒体验证 |

艺术层面额外审查：语速是否符合人物、观众能否听懂、对白如何与动作/停顿构成节奏、是否因剧作信息密度过高而无法在 15 秒中自然呈现。不以“语速数值达标”代替优秀表演。

## 六、示例：女儿与父亲在雨夜车站

**角色声音身份（第 2 区）**：

- 女儿：普通话，自然口语，声线偏清冷，音高倾向平稳，**基准语速中等偏慢**，中性基础样音一个（真实资产是否存在须实际确认）。
- 父亲：声线更低沉、气息稳定，**基准语速偏慢**；具体声音参考亦待真实创建或导入。
- 环境声音：雨夜车站的雨声、远处站台广播/列车声，是该地点的可复用声音设定。
- 关键声：旧钥匙碰撞或落地，可作为剧情需要时的声音参考。

**导演表演（第 3 区）**：父亲递钥匙前，前半句平静，后半句更慢、略显犹豫，最后留白；女儿本来习惯较慢，但争执一句短台词突然变快。

**分镜规划（第 4 区）**：把具体台词、父女说话者、当前表演语速、动作和停顿排入 Shot04 的两个计划 Clip B1/B2；如果同一持续对白跨原生续接边界，要特别检查声音连续性与模型是否有相关能力。

**生成审查（第 5/6 区）**：不因为实际续接保存了 Motion Context 就自动断言音色/语速无缝延续。必须观看**真实生成音视频**，评估音色、实际语速、口型及环境声是否符合本镜头导演意图。

## 七、待创作者后续审定的细节

1. **V-01 基准语速默认控件**：推荐先用直观的五档/文字加可试听样音；量化仅辅助，避免人为精度和模型不支持字段。
2. **V-02 真实参考样本**：按本稿第 2.6 节建议主要有台词角色一条干净中性基础样音（仅作为质量目标），表演样音按需；待确认缺样音时的生产放行策略及具体模型能力。
3. **V-03 语速与停顿两字段**：建议独立编辑，并能按台词覆盖；不要“一个速度滑块同时控制快慢和停顿”。
4. **V-04 环境/道具声资产**：建议按剧本/导演重要性创建，允许仅有正式文字设定或必要真实媒体。
5. **V-05 模型适配与测量**：必须核实当前 H3 等路由的参考音频、语速表达、原生音画、媒体时长和 QA 条件，再制定可执行参数与测试阈值。

用户已经明确要求将**语速**写入声音资产规范；以上具体方案尚未逐项批准。

**下一步设计建议**：创作者先审定第 2.6 节主要角色样音最低目标与“未实测 H3 参考能力时的生产放行”原则，随后确定**场景完整多视角宫格的固定视图组合与出图质量验证**。任何新的图形、声音生成或代码实现均需单独启动。
