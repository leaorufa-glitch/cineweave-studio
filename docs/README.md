## 文档状态标准

- **已确认**：创作者明确确认的项目决定；如需改变，必须记录新决策与影响。
- **草案**：供创作者审阅的新设计，不自动升级为工程硬约束。
- **待核实**：需要准确模型资料、真实接口或可播放样片证据的事实。
- **被替代**：保留历史修订，不作为现行实施依据。
