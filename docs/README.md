## 文档状态标准

- **已确认**：当前项目中由创作者明确确认的决定；如需变更，必须记录新的决策及其影响。
- **草案**：专业设计提案，正在等创作者审阅；不自动升级为开发规范。
- **待核实**：需要准确文档、真实接口或样片运行支持的事实，不冒充已实现。
- **被替代**：保留修订历史，不再作为现行实施依据。
