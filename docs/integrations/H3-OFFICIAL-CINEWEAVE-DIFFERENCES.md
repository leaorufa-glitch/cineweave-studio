# MiniMax H3 官方规范与 CineWeave 中文增强指南差异对照表

状态：**部分对照**，2026-10-12。官方三份原文已按 [固定版本](H3-PROMPT-SPEC.md)核实；创作者提及的《MiniMax H3 Singularity 视频提示词编写规范｜深度中文版.md》原文件尚未在项目、旧工作树或附件中取得。下表“中文增强”列只依据创作者在 CW-H3-PROMPT-RECOVERY-02 工单中明确列出的主题，不声称已逐条阅读该文档。取得原文件后再补逐条页段依据。

| 事项 | 已核实的 MiniMax 官方格式 | 创作者概述的中文专业增强 | 编译处理与优先级 |
| --- | --- | --- | --- |
| 模式 | T2VA/I2VA/FL2VA/L2VA 基础三字段；Ref2VA 六字段 | 按剧情、导演目标增加专业视听细节 | 先选择模式再组织专业内容；绝不把六字段套到基础模式 |
| 可见主体 | `<Subject N>` 表示可复用的可见内容；`<Picture N>` 是源图或具体帧锚 | 人物与参考关系、完整人物/场景/道具图板 | 每张正式图板保持一个 MediaFile/Revision；Reference Map 可从它定义多个 Subject |
| 动作 | 按播放顺序写可观察动作与状态变化 | 连续动作链、物理反馈、因果 | Execution Plan 的 Beat 保留起因、动作、效果和终态；编译器不得凭空补剧情 |
| 摄影与切镜 | `[Shot 1]` 无起始时间；后来实际切镜用 `At MM:SS.mmm` | 摄影机运动、调度、长镜头连续性 | Beat 和 Shot 分开；同 Shot 多 Beat 不擅自切镜；只有已规划切换才新增 Shot 标签 |
| 表演与对白 | `(Sx)` 稳定身份，`<d>[Language] 原文</d>`，原文不翻译 | 微表演、语速和独立停顿 | 表演、语速和停顿写在对白标签外；标签内保留原文 |
| 声音 | `overall_soundscape`、`non_diegetic_music` 分层；对白/歌词在时间线 | 声画同步、环境声、道具声与音乐 | 按声源和发生时点分别编译，不把角色可听音乐写成非叙事配乐 |
| 光照材质与特效 | 画面描述应具体可见，示例不构成固定栏目 | 灯光、材质、视觉特效、物理反馈 | 只写执行计划已给出的可观察细节，放进官方正文，不新增自定义官方字段 |
| 引用保留关系 | Ref2VA `retention_analysis` 使用固定枚举 | 资产连续性与身份保持 | 显式选择保留关系；不凭模板推断复制或改造事实 |
| Provider 与续接 | Prompt Skill 本身未定义 Darl/自有服务器接口 | 镜头连续性和长镜头组织 | Provider 能力另行核验；文字连续性、尾帧和普通视频参考不等于 Motion Context |

优先级：官方已核实模式格式 → CineWeave 正式产品/导演决定 → 中文专业增强 → 工程便利。专业增强不得改官方字段；官方格式也不得改变导演已确认的镜头意图。
