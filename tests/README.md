# 验收资料

状态：验收计划待设计；当前无应用代码与自动化测试。

此目录预留工程验收场景和未来测试资料。
V1.2 阶段拟用约 60–90 秒短片案例检验业务设计，案例内容及具体标准尚未审定。

后续应覆盖：
- 六区职责及 LLM 专业参与是否完整，跨区是否重复或遗漏。
- 同一 Shot 从导演设计到分镜落实的身份与版本是否连续。
- 多 Shot 合并生成与长 Shot 分段续接是否分别表达正确。
- 剧本、角色或导演变更能否定位影响范围。
- 原生续接能否绑定指定上游结果，批量任务依赖及失败恢复是否成立。
- 素材、选用 Take、成片组织及导出能否追溯。

以上是验收范围的预留说明，不代表测试已经编写、执行或通过。
