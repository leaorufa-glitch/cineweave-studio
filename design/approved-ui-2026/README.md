# CineWeave Studio · 七页面 UI/UX 交互原型

这是根据讨论中收敛的产品结构制作的 **前端演示原型**，包含一个首页和六个 AI 影视制作工作区。

## 如何打开

1. 最方便：打开同目录之外的 `CineWeave_Studio_七页面交互原型_2026.html`。它是独立文件，图片、演示视频、CSS、JavaScript 均已内嵌，无需部署、联网或安装依赖。
2. 源码版：解压源码包，打开 `index.html`；保持 `app.js`、`style.css` 和 `media/` 文件夹在同一目录下。使用本地静态服务器亦可。

## 七个页面

| 页面 | 核心展示与操作 |
| --- | --- |
| 首页 | AI 创意输入、小说/剧本/参考图附件入口、项目列表、我的菜单与资产库入口 |
| 01 故事与剧本 | 影片概述、审读要点、主要人物、完整剧本阅读/版本比较、确认 |
| 02 角色与美术 | 统一美术风格、人物/场景/道具多行平铺/列表、角色多 Look、声音库候选、描述和 Prompt 编辑、上传/选择入口 |
| 03 导演创作 | 整体导演意图、预计时长/场次/Shot、逐场导演方案及 Shot 摘要 |
| 04 分镜与生成规划 | Clip 列表、Clip 内多个 Shot 的详细动作描述、资产参考、可选分镜图、跨 Clip 续接条件、通用提示词 |
| 05 生成制作 | Clip 任务队列、模型检查、模拟任务状态、Take 比较模板与续接依赖 |
| 06 审片与成片 | 演示视频播放器、轻量后期时间线、审片检查项、Take 选择和导出设置 |

## 原型与真实产品的区别

- 图像和视频均是 UI 展示模板。视频是由已有静态画面拼接出的演示剪辑，并非 H3 或任何视频模型生成。
- 没有真实的 AI 生成、TTS、文件上传到服务器、图像模型调用、费用扣除、成片渲染或持久化后台。
- “让 AI 修改”是对话交互模板，不会调用真实 AI。
- “模型选择”“生成任务”“确认”“采用”“导出”用于验证界面布局与状态交互，不代表已经执行。
- 用户在页面上编辑的内容只保留在当前前端会话内，刷新后重置。
- 自托管 H3 优先只是已确定的产品方向。真正的 API 能力、参考图兼容性、Motion Context 与费用必须在后续开发中核验。
- 第三区创建导演 Shot，第四区继续完善同一个 Shot；Generation Clip 是模型生产单位。一个 Clip 可含多个 Shot，一个不中断的 Shot 也可跨多个 Clip。
- 每个 Look 正式标准为一张 2:3 的 2×2 图板，场景和关键道具正式标准为 1+3 整板。原型内的旧视觉模板不声称满足这些标准。
- 演示人物、场景、时长、Clip、Shot 及音画描述用于表达 UI 信息层级，不是正式制作文件。

```text

media/               -- 演示图片和静态拼接视频
README.md            -- 本说明
DESIGN_BASELINE.md   -- 收敛的信息架构与操作边界
```
